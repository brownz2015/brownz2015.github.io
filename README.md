# Zachary Brown personal site

This folder is ready to become the root of the `brownz2015.github.io` GitHub Pages repository.

## Publish it

1. On GitHub, create a **public** repository named exactly `brownz2015.github.io`.
2. Upload every file in this folder, including `cv.pdf`, to the repository root.
3. In the repository, go to **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, then choose the `main` branch and the `/ (root)` folder. Save.
4. GitHub will publish the site at `https://brownz2015.github.io`, usually within a few minutes.

## Update the CV

Replace `cv.pdf` with a newer PDF that uses that exact filename. The site’s CV buttons will automatically point to it.

## Local preview

Open `index.html` in a browser to preview the site before uploading.
